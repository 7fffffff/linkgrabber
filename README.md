### Hello ###

Link Grabber is an extension for Google Chrome that extracts links from an HTML page and displays them in another tab. 

#### Features
- Extracts all hyperlinks from the current webpage.
- Displays links in a new tab for easy access.
- Simple and user-friendly interface.

#### Installation
1. Download the extension from the [Chrome Web Store](https://chrome.google.com/webstore/detail/link-grabber/caodelkhipncidmoebgbbeemedohcdma).
2. Click "Add to Chrome" and follow the prompts to install.

#### Usage
- After installation, click the Link Grabber icon in the Chrome toolbar to extract links from the current page.
